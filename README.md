# Abyssal Front

Подводный горизонтальный шутер, вдохновлённый *In the Hunt* (Irem, 1993). Аркадная игра на чистом JavaScript с процедурным ландшафтом, многоуровневым оружием и ретро пиксель-артом.

![Game Screenshot](game/generated/atlas.png)

## Возможности

- **Классический аркадный экшен** — горизонтальный скроллинг, подводные бои
- **Четыре типа оружия** — Торпеды, Пулемёт, Волновой луч, Дробовик (по 3 уровня апгрейда каждый)
- **Система глубинных бомб** — 3 уровня улучшений с площадным уроном
- **Динамичный бой** — оружие + бомбы выпускаются одновременно
- **Процедурный ландшафт** — пещеры через Catmull-Rom интерполяцию с детерминированной генерацией
- **Ретро-аудио** — процедурная чиптюн-музыка и синтез звуковых эффектов
- **Битвы с боссами** — многофазовые столкновения с механикой слабых точек
- **Система чекпоинтов** — сохранение прогресса при смерти

## Технологический стек

### Ядро
- **Vanilla JavaScript (ES6+)** — без фреймворков, без сборки
- **HTML5 Canvas 2D** — pixel-perfect рендеринг в нативном разрешении 480×270
- **Web Audio API** — синтез звука в реальном времени

### Архитектура
- Фиксированный timestep 60 FPS с аккумуляцией дельты
- Entity-component-подобный дизайн с plain objects
- Процедурная генерация через seeded PRNG (Mulberry32)
- Батчинг через texture atlas для оптимальных draw calls
- Object pooling для минимального давления на GC

### Ассеты
- Единый texture atlas 1024×512
- Рендеринг bitmap-шрифта
- Без внешних зависимостей

## Быстрый старт

### Запуск локально
```bash
cd game
python -m http.server 8080
```
Открыть http://localhost:8080

### Управление
- **WASD** / **Стрелки** — Движение
- **J** / **Z** / **Пробел** — Оружие + бомба (удержание)
- **K** / **X** — Только бомба
- **Esc** — Пауза
- **M** — Переключить звук
- **F1** — Режим отладки (G = бессмертие, F2 = прыжок к боссу)
- **Геймпад** поддерживается

## Геймплей

Управляйте подводной лодкой Granvia через подводные траншеи, уничтожайте вражеские силы, собирайте апгрейды оружия. Каждый тип оружия имеет 3 уровня:
- **Торпеды** — ускоряющиеся снаряды с самонаведением
- **Пулемёт** — скорострельные трассирующие заряды
- **Волновой луч** — пробивающая энергетическая волна
- **Дробовик** — разнонаправленные дробинки

**Глубинные бомбы** улучшаются независимо (LV1-3):
- LV1: Одна бомба
- LV2: Двойной залп
- LV3: Тройной залп с увеличенным радиусом взрыва

Оружие + бомбы выпускаются вместе по основной кнопке огня для максимального урона.
